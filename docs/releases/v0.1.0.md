A native Windows version of *Valkyria Chronicles II* for PSP, built on your PC from your own disc image. This download contains no game data and no console keys.

**Beta:** this first release has been tested into the first battle.

### You need

- Your own disc image (`.iso` or `.cso`) of Valkyria Chronicles II (North America, ULUS-10515).
- A decrypted copy of the game's executable, made from that disc with [PPSSPP](https://www.ppsspp.org): turn on **Settings > System > Developer tools > Dump decrypted EBOOT.BIN on game boot**, start the game once, and use the `ULUS10515_EBOOT.BIN` it saves in `PSP/SYSTEM/DUMP` of its memory stick folder. The launcher finds it there, or you can pick it.
- The free **Visual Studio 2022 Build Tools** with "Desktop development with C++", which compiles the game on your PC.

### How to play

1. Download `VC2Recompiled-v0.1.0-Windows-x64.zip` below and unzip it.
2. Run `VC2Launcher.exe`, pick your ISO (and the PPSSPP dump, if it isn't found), then press **Recompile** (about 2 minutes) and **Play**.

Or install it through [RecompLauncher](https://recomplauncher.com), which uses the included `recomplauncher.json` and asks for both files.

### What works

- Boot, menus, save creation, the opening movies with sound, story scenes, and the first battle (briefing, squad placement and the tactical map).
- A steady frame rate: 30 FPS in story scenes and on the battle map and 60 FPS in menus, exactly as on a PSP.

### PC features

- Up to 8× resolution, MSAA, FXAA, anisotropic filtering and texture upscaling.
- Windowed, borderless or fullscreen, V-Sync and an FPS counter.
- Keyboard and controller support; hold ` (backquote) to fast-forward (3× speed).
- An optional 60 FPS mode for battles and maps (experimental, off by default): the engine's own time step keeps the game at its normal speed.

### Known limitations

- Later chapters are not tested yet.
- Saves only work with this port, not with a real PSP.
- No local multiplayer.

The launcher's About tab shows this build's version and commit. Use "Copy build information" when you report a problem.
